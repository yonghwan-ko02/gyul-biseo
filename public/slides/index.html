지능형 고객 매칭

🔍 Dice Coefficient 유사 검색
  • 한글 바이그램(Bigram) 최적화 알고리즘
  • 유사도 0.15 이상 상위 5명 추천 칩 렌더링
  • 정확 매칭 시 주소·연락처 자동 로드
  • 중복 고객 생성률 제로화

  • 1단계: 이름 + 번호 일치 → 기존 고객 사용
  • 2단계: 번호 없으면 → 기존 계정에 번호 등록
  • 3단계: 번호 상이 → 새 고객 분리 생성
