# PRD V3 — Talk & Track: 감귤 농가 맞춤형 대화형 비즈니스 데이터 관리 솔루션

> **버전:** V3 | **작성일:** 2026-05-27 | **상태:** 확정

---

## 1. 프로젝트 개요

* **서비스명:** Talk & Track (귤 비서)
* **한 줄 정의:** 수확 및 포장 작업 중 음성 메시지만으로 출하, 정산, 영농 이력을 기록하고 관리하는 감귤 농가 전용 AI 비서 서비스
* **핵심 목표:** 5070 농업 종사자의 기기 조작 진입장벽을 제거하고, 수확 철 정신없는 와중에 발생하는 외상 누락 및 기억 공백을 방지하여 농가의 실질 수입을 지킴.

---

## 2. 배경 및 필요성

* **문제점:** 감귤 수확기는 눈코 뜰 새 없이 바빠 장갑을 벗고 정산 앱을 켜서 타이핑할 여유가 없음. 이로 인해 단골 직거래, 지인 외상 거래 내역이 수기 장부나 기억에만 의존하다 누락되어 정산 손실이 발생함. 친환경/GAP 인증에 필요한 영농일지 기록도 번거로운 고역임.
* **기회:** LLM의 구어체 인식 능력을 활용하면 일상적인 방언이나 현장 은어가 섞여 있어도 품종, 규격, 거래처, 정산 상태를 정확히 추출하여 데이터화할 수 있음.

---

## 3. 주요 타겟 사용자

* 현장에서 양손에 흙을 묻히거나 장갑을 끼고 일하는 50대~70대 감귤 농장주
* 노지 감귤, 타이벡, 만감류(한라봉, 레드향 등) 등 다양한 품종을 직거래와 도매(청과/작목반)로 다변화하여 판매하는 농가
* 영농일지 작성, 외국인 일용직 인력 관리, 미수금 정산 관리를 수기로 하느라 골머리를 앓는 소규모 농장 리더

---

## 4. 핵심 기능 요구사항

### 4.1 감귤 특화 스마트 멀티모달 인풋 (Voice/Photo to Data)

* **감귤 전용 STT 및 엔티티 추출:** 제주 방언, 현장 은어(예: 콘테나, 조생, 대과, 로얄과 등), 품종명(노지, 타이벡, 황금향, 레드향 등), 규격 및 포장 단위(3kg, 5kg, 10kg)가 포함된 구어체 음성을 정확히 파싱하여 정형 데이터로 분류함.
* **누락 정보 되묻기 컨텍스트 유지:** "영철이네 귤 20박스 보냄"과 같이 필수 정보가 누락된 경우, AI가 추가 질문을 던져 장부를 완결함.
  * 예: "영철 고객님께 보낸 귤 품종이 노지인가요, 황금향인가요? 택배비 포함 여부도 말씀해 주세요"
* **현장 소음 대비 대체 UI:**
  * 선별기 소음 등으로 음성 인식이 실패할 경우 카카오톡 퀵 리플라이 버튼(품종/규격 터치 선택) 제공
  * 화이트보드나 종이에 적은 수기 장부를 사진으로 찍어 전송하면 OCR + LLM이 결합하여 데이터를 자동 입력하는 멀티모달 기능 지원

### 4.2 데이터 정정 및 자연어 수정 로직 (Natural Language CRUD)

* **자연어 기반 장부 수정/삭제:** 복잡한 메뉴 이동 없이 말로 장부를 정정할 수 있도록 지원함.
* **시나리오 예시:**
  * "아까 청과로 보낸 거 50박스가 아니라 40박스야 수정해 줘"
  * "어제 삼춘네 외상 기록한 거 지워줘"
  * → AI가 해당 건을 찾아 안전하게 데이터를 변경하고 변경 완료 내역을 복창함

### 4.3 미수금(외상) 관리 및 원클릭 정산서 발송

* **자연어 기반 미수금 조회:** "지금 정산 안 된 외상 총 얼마고 누구누구 있냐?" → 미정산 목록과 총액 요약 답변
* **원클릭 카카오톡 정산서 공유:** AI가 미수금 내역을 브리핑한 후 정산서 공유 버튼 제공 → 터치 시 거래처에 외상 내역 및 계좌 정보 메시지 즉시 발송
* **수동 입금 매칭:** "영철이네 30만 원 입금됐어" → 기존 미수금 잔액에서 차감하고 최신 잔액 반영

### 4.4 인증용 작업 이력 및 인력 관리

* **영농일지 자동 축적:** 일상 기록 → GAP 인증 및 친환경 인증 제출용 표준 영농일지 양식 데이터로 변환
* **물량 흐름 추적:** "올해 지금까지 나간 타이벡 총 몇 박스냐?" → 즉시 답변 + 전년 동기 대비 추이 비교
* **단기 노무 관리:** 수확기 집중 투입되는 일당제 인력의 이름, 근무 일수, 지급 일당 음성 기록

## 5. 기술 스택 및 아키텍처

| 레이어 | 기술 |
|--------|------|
| 언어 모델 | GPT-4o 또는 Llama 3.1 기반 파인튜닝 모델 |
| 관계형 DB | PostgreSQL (출하량, 단가, 인력 정산) |
| 벡터 DB | ChromaDB (과거 영농 특이사항·거래 맥락) |
| 프레임워크 | LangChain / LangGraph 기반 대화형 에이전트 |
| 인터페이스 | 카카오톡 챗봇 API (최우선) + 모바일 웹뷰 |

## 6. 사용자 시나리오

1. **기록:** 수확 현장에서 장갑을 낀 채 음성 메시지 전송
   > "오늘 서귀포 청과로 한라봉 5킬로 상짜리 50박스 보냈고 단가는 3만 원 잡았다"

2. **처리:** AI가 엔티티 분류 후 DB 저장
   > 품종(한라봉), 규격(5kg/상), 수량(50), 단가(30,000), 거래처(서귀포 청과), 결제상태(미수금 150만 원)

3. **정정:** 말실수 수정
   > "아 참, 50박스가 아니고 45박스다"
   > AI: "서귀포 청과 한라봉 수량을 45박스로 수정했습니다. 미수금은 135만 원입니다"

4. **정산:** 정산서 발송
   > "청과 미수금 정산서 보내줘"
   > AI: 내역서 생성 + 터치 한 번으로 청과 담당자에게 카카오톡 발송

## 7. 성공 지표 (KPI)

| KPI | 설명 |
|-----|------|
| 미수금 정산 성공률 | 외상 입력 후 실제 정산 성공 및 누락 차단율 |
| CRUD 정확도 | 자연어 수정을 통한 데이터 정정 성공률 |
| 음성 완결성 | AI가 되묻지 않고 한 번에 올바르게 파싱한 비율 |
| 재방문율 | 손실 예방 알림을 통한 주간 유저 재방문율 |

## 8. 향후 확장 계획

* **자동 정산 매칭:** 오픈뱅킹 API 및 계좌 입금 문자(SMS) 알림 연동을 통한 외상값 자동 정산 매칭
* **택배 연동:** 카카오톡 직거래 주문서 캡처 → 주소·수량 파싱 → 택배 송장 출력 (우체국, CJ대한통운)
* **수확 예측:** 누적 데이터 기반 내년도 수확 시기별 예상 매출 추정 가이드
