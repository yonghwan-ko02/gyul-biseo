# PRD V4 — Talk & Track: 감귤 농가 맞춤형 대화형 비즈니스 데이터 관리 솔루션

> **버전:** V4 (Phase 1 MVP 고도화 반영) | **작성일:** 2026-05-31 | **상태:** 확정 및 실전 검증 완료

---

## 1. 프로젝트 개요

* **서비스명:** Talk & Track (귤비서)
* **한 줄 정의:** 수확 및 포장 작업 중 음성 메시지만으로 출하, 정산, 영농 이력을 기록하고 관리하는 감귤 농가 전용 AI 비서 서비스 (현재 고도화된 Phase 1 MVP 구현 완료 및 실전 검증 완료).
* **핵심 목표:** 5070 농업 종사자의 기기 조작 진입장벽을 제거하고, 수확 철 정신없는 와중에 발생하는 외상 누락 및 기억 공백을 방지하여 농가의 실질 수입을 지킴.

---

## 2. 배경 및 필요성

* **문제점:** 감귤 수확기는 눈코 뜰 새 없이 바빠 장갑을 벗고 정산 앱을 켜서 타이핑할 여유가 없음. 이로 인해 단골 직거래, 지인 외상 거래 내역이 수기 장부나 기억에만 의존하다 누락되어 정산 손실이 발생함. 친환경/GAP 인증에 필요한 영농일지 기록도 번거로운 고역임.
* **기존 LLM의 한계 극복:** 소형 온디바이스/로컬 8B 모델은 다중 연쇄 번복이나 범위형 모호성이 섞인 극단적인 구어체 파싱에서 성능적 한계를 보였으며, 대형 70B 모델은 API 제한(TPM/TPD) 및 고비용 문제로 상용화에 어려움이 있었음.
* **기회 및 해결책:** 그록(Groq) 클라우드 기반의 최고 성능 모델인 **Llama 3.3 70B**로 엔진을 전격 업그레이드하고 프롬프트를 70% 초경량화하여 분당 토큰 제한을 우회하였으며, STT 공백 자동 전처리 및 플레이스홀더 안전망을 코드 단에 배치함으로써 제주 방언이나 현장 소음 속에서도 100% 무결한 데이터 추출에 성공함.

## 3. 주요 타겟 사용자

* 현장에서 양손에 흙을 묻히거나 장갑을 끼고 일하는 50대~70대 감귤 농장주
* 노지 감귤, 타이벡, 만감류(한라봉, 레드향 등) 등 다양한 품종을 직거래와 도매(청과/작목반)로 다변화하여 판매하는 농가
* 영농일지 작성, 외국인 일용직 인력 관리, 미수금 정산 관리를 수기로 하느라 골머리를 앓는 소규모 농장 리더

## 4. 핵심 기능 요구사항

### 4.1 감귤 특화 스마트 멀티모달 인풋 (Voice/Photo to Data)
 
* **Llama 3.3 70B 기반 AI 파싱 엔진:** 그록 클라우드의 Llama 3.3 70B 모델을 적용해 복잡한 자연어 맥락을 정확히 인지하며, 프롬프트 압축 기술(약 5.5k -> 1.5k 토큰)로 속도 지연(3~4초 내외)과 일일 사용량 한도를 완벽히 극복함.
* **STT 자간 공백 전처리 (Digit Spacing Consolidation):** 선별기 등 현장 소음으로 인해 "3 0 0 만 원", "5 0 박스"처럼 쪼개져 인식된 STT 문자열을 AI 전달 전에 정규식(`/(\d)\s+(?=\d)/g`)으로 자동 병합·복원하여 수치 왜곡을 차단함.
* **결정론적 플레이스홀더 안전 필터 (Deterministic Safety Filter):** 대화 내용 중 필수 항목(예: 거래처명)이 누락되어 AI가 `unknown`, `none` 등으로 채워 임의 등록하려 할 때, 코드가 이를 감지하여 되묻기(`clarify`) 액션과 맞춤형 질문 카드로 유도해 금융 장부 오염을 원천 차단함.
* **한글 숫자 및 금액 표현 환산:** "쉰 콘테나" -> 수량 50, "열다섯 박스" -> 수량 15, "오백만 원" -> 5,000,000 등 한글 발화 수치 정보를 100% 디지털 수치로 자동 변환.
* **B2C 묶음 수량 보존:** "한라봉 5kg 3박스" 파싱 시 품종을 "한라봉 5kg", 수량을 3으로 1:1 보존하며, 둘을 곱해서 15로 왜곡하지 않음.
* **제주 방언 및 구어체 완벽 정화:** 실전 밭일 중에 외치는 구어체, 슬랭, 주저함("그 뭐냐"), 반말/존댓말 혼용, 문장 처두의 호격 조사("영철아", "삼춘")를 거래처명으로 오분류하지 않고 소거 전처리함.

### 4.2 대화형 데이터 검증 (Confirmation Card) 및 자연어 CRUD
 
* **양방향 대화형 데이터 확인 카드 (`ConfirmationCard.tsx`):** 음성/텍스트로 주문이나 출하를 등록할 때 즉시 DB에 저장하지 않고, 채팅창 내부에 글래스모피즘 기반 정보 확인 카드를 동적으로 렌더링함.
* **실시간 데이터 교정 인터랙션:** 사용자가 카드에서 직접 수량 증감(-, +), 품종 칩 선택, 주소/연락처 입력 칸을 터치로 수정할 수 있는 터치 친화형 UI를 장착하여, 최종 [장부에 바로 등록] 클릭 시 완벽히 교정된 정보만 DB에 적재되도록 연동함.
* **자연어 기반 장부 수정/삭제:** "아까 서귀포 청과 보낸 거 45박스로 수정해 줘", "어제 삼춘네 외상 기록한 거 지워줘" 등 음성 명령 시 AI가 해당 대상을 찾아 안전하게 데이터를 변경하고 결과를 복창함.

### 4.3 미수금(외상) 관리 및 원클릭 정산서 발송
 
* **미수금 수동 정산 완료 및 실시간 동기화:** 농장주가 입금을 확인한 후 AI 명령 없이도 간편하게 터치로 장부를 털 수 있는 대형 유리모피즘 "입금 완료 확인" 모달을 탑재 (52px 이상의 대형 고대비 버튼 배치로 오터치 방지).
* **Next.js 라우터 캐시 강제 무효화 (Revalidation):** 결제 완료 처리 즉시 `revalidatePath`를 호출하여 Next.js 서버 및 브라우저 라우터 캐시를 만료시킴으로써, 대시보드 현황 탭과 장부의 미수금 총액이 별도의 수동 새로고침 없이 100% 동기화되도록 완비함.
* **미수금 산출 공식 단일화:** 대시보드와 정산 화면 간의 미수금 계산식을 `outstandingAmount || totalAmount || (quantity * unitPrice)` 형태로 일체화하여 정합성 오류를 완벽히 해결함.
* **원클릭 카카오톡 정산서 공유:** 미수금 내역과 농가 계좌 정보를 카카오톡 메시지로 즉시 전송할 수 있는 퀵 텍스트 복사 및 공유 링크 제공.

### 4.4 인증용 작업 이력 및 인력 관리
 
* **영농일지 자동 축적:** 일상 작업 내용을 "농약 살포", "가지치기" 등 카테고리별로 기록하면 GAP 인증 제출용 표준 영농일지 데이터로 자동 전환함.
* **물량 흐름 추적:** 연간/시즌별 출하 품종 및 박스 규모를 데이터베이스에서 정확히 조회하여 작년 동기 대비 추이를 비교함.
* **단기 노무 관리:** 수확기 집중 투입되는 일당제 외국인 및 단기 근로자의 근무 일수와 일당 지급 현황을 기록.

### 4.5 시니어 고객 관리 (CRM) 및 고객별 배송 이력 관리
* **고객별 프로필 정보 통합:** 거래처 및 소비자 개개인의 이름, 연락처, 기본 배송지 주소를 검색 필터와 함께 큼직하게 노출하는 시니어 특화 CRM 화면 제공.
* **원클릭 편의 기능 (A11y):**
  * **원클릭 주소 복사:** 택배 송장 입력을 손쉽게 하기 위해 배송지 주소를 클릭 한 번으로 클립보드에 즉시 복사.
  * **원클릭 전화 걸기 링크:** 연락처 클릭 시 모바일 다이얼러로 즉시 연결 (`tel:` 프로토콜).
* **상세 배송/주문 이력 타임라인:** 각 고객별 프로필 카드를 열면 과거의 모든 출하완료(`shipped`) 및 주문접수(`pending`) 상태의 배송 이력을 시간 순서대로 조회 가능. 결제 완료는 녹색, 미수금(외상)은 고대비 적색으로 명확히 구분하여 시인성 확보.

### 4.6 데이터 기반 AI 경영 및 영농 의사결정 인사이트
* **실시간 AI 영농 진단 위젯:** 대시보드 최상단에서 농가의 실시간 데이터를 분석하여 경영 진단을 내리는 AI 위젯 탑재.
* **실시간 연동 데이터 지표 분석:** 
  1. 이번 시즌 총 예상 매출액 (출하 건별 실제 단가 및 수량 합산)
  2. 현재 전체 외상 잔액 및 미수금 비율 (%)
  3. 미수금이 가장 높은 최대 채무 거래처명 및 연체 금액
  4. 총 출하 상자량 및 신규 접수된 발송대기 주문서 개수
  5. 영농일지 누적 작성 횟수
* **친근한 표준어 처방 브리핑:** 위 핵심 지표들을 Prisma 집계 함수로 연산하여 LLM 프롬프트에 동적 삽입, 농가 경영에 도움이 되는 다정하고 전문성 있는 경영 처방 브리핑을 실시간 생성함.
* **펄스 애니메이션 (Skeleton Loader):** AI 분석 대기 시 시각적 피로를 줄여주는 펄스 애니메이션 효과로 프리미엄 품질 선사.

### 4.7 [NEW] 택배 의뢰서 이메일 발송 자동화 및 즉각적 피드백 루프
* **Nodemailer 기반 이메일 자동 발송:** 설정 페이지에 등록된 제휴 택배사 메일 주소로 발송대기(`pending`) 중인 출하 세부 사항(품종, 수량, 배송지 주소 등)을 자동 전송하는 백엔드 메일링 파이프라인 구축.
* **인터랙션 피드백 및 상태 즉시 전환:** 사용자가 '택배사에 의뢰서 즉시 전송'을 클릭하면 메일이 발송되며, 전송 성공 즉시 DB 상태를 `shipped`(출하 완료)로 변경하고 버튼을 '메일 재발송'으로 상태 전환함과 동시에 대시보드 대기 주문 배지를 실시간 차감하여 중복 전송 및 오동작을 완벽 차단함.

### 4.8 [NEW] CSS Grid 기반 월간 캘린더 장부 뷰 및 기간 필터
* **월간 캘린더 그리드 뷰 (`LedgerCalendar.tsx`):** CSS Grid를 적용하여 시니어 친화적인 월간 달력 화면을 구축. 날짜별 출하 빈도와 상태(발송대기=황색, 미수금=적색, 완납=녹색 점 마커)를 직관적으로 확인 및 터치 제어 가능.
* **조회 기간 필터 바 (Period Filter):** 전체, 주별(7일), 월별(30일), 사용자 정의 기간(캘린더 범위 선택)을 제공하여 장부 데이터를 실시간으로 유연하게 필터링.
* **상세 수정 모달 (`EditShipmentModal.tsx`):** 수량 조절 버튼(`-, +`), 품종 선택 칩, 상자당 단가 조절 등을 지원하는 풀스크린 모달 제공. 단가 및 수량 수정 시 총액과 미수금 잔액이 자동으로 재계산되어 DB와 실시간 동기화됨.

### 4.9 [NEW] 대시보드 7대 핵심 분석 위젯
1. **발송대기 주문 알림 배너 (`PendingOrderBanner`):** 발송 대기 중인 주문이 존재할 경우 대시보드 최상단에 고대비 배너를 조건부 노출하여 미발송 누락을 원천 차단.
2. **빠른 액션 바 (`QuickActionBar`):** 채팅·발송대기·정산서·장부 4개 핵심 페이지로의 원터치 네비게이션 및 실시간 대기 주문 수, 미수금 거래처 수 배지 표시.
3. **전월 대비 성장률 인디케이터 (`GrowthIndicator`):** 오늘 출하·미수금·이번 달 매출에 대해 전월 동기 대비 증감률을 산출하여 색상 코딩(녹색=성장, 적색=하락)으로 표시.
4. **차트 탭 전환 (`DashboardChartTabs`):** 7일 주간 출하량 바차트와 6개월 월간 매출 추이 AreaChart(그라데이션 fill) 간 탭 전환 제공.
5. **품종별 매출 도넛 차트 (`DashboardVarietyChart`):** Recharts PieChart를 활용하여 노지감귤·타이벡·한라봉 등 품종별 매출 점유율 및 상자 수 실시간 시각화.
6. **거래처 미수금 TOP 5 랭킹 (`TopUnpaidRanking`):** 미수금 상위 5개 고객의 이름, 랭킹 배지, 미수금 잔액, 전체 미수금 대비 점유율 프로그레스 바 표시로 채권 위험 관리.
7. **영농일지 최근 기록 위젯 (`FarmLogWidget`):** 최근 일지 2건을 카테고리 아이콘과 상대적 경과 시간으로 노출하며, 5일 이상 미기록 시 기록 독려 경고 노출.

### 4.10 AI 응답 표준어 및 볼드체 제거 규칙
* AI의 모든 사용자 대상 답변은 **표준어**로 일관되며 친근하고 정중하게 표현 (~습니다, ~세요).
* 마크다운 볼드체(`**텍스트**`)는 시니어용 모바일 화면에서 가시성을 해치고 글자가 깨져 보일 수 있으므로 답변에서 완전히 배제함 (제주 방언 맵은 오직 유저 입력 이해용으로만 활용).

## 6. 사용자 시나리오

1. **대화형 기록 및 검증:**
   * 농장주가 장갑을 낀 채 채팅창에 대고 "오늘 서귀포 청과 한라봉 5kg 3박스 보냈고 박스당 3만 원 잡았다"라고 말함.
   * AI가 자간 공백과 방언 전처리를 거쳐 파싱하고, DB에 바로 저장하지 않은 채 수량 `3`과 단가 `30,000` 등이 담긴 **양방향 컨펌 카드**를 채팅창에 노출함.
   * 농장주가 내용을 확인하고 [장부에 바로 등록]을 클릭하면 DB에 안전하게 출하 데이터가 적재됨.

2. **미수금 조회 및 수동 정산:**
   * 대시보드 TOP 5 미수금 위젯에서 연체 내역 확인 후, 상세 장부 또는 정산 탭으로 이동.
   * 농장주가 입금을 확인한 후 정산 완료 버튼 클릭 -> 풀스크린 "입금 완료 확인" 모달이 노출됨 -> [완료] 터치 시 즉시 수납 상태 변경 및 대시보드 실시간 동기화 반영.

3. **택배 의뢰 메일 발송:**
   * B2C 주문이나 출하 대기건에 대해 '택배사에 의뢰서 즉시 전송' 클릭.
   * 메일 발송 API 작동 후 '재발송' 버튼으로 전환되며 출하 상태가 즉시 `shipped`로 전환되어 장부에 반영됨.

## 8. 향후 진행 목표 및 확장 계획

### Phase 2: 카카오톡 통합 및 다채널 연동
* **카카오톡 챗봇 채널 연동:** 웹 브라우저 진입을 넘어 카카오톡 챗봇 채널로 사용자 인터페이스를 다변화하여 현장 진입 장벽 최소화.
* **알림톡 정산서 전송:** 텍스트 복사 공유를 넘어 카카오톡 알림톡/비즈니스 API를 연동하여 거래처에 정식 정산 메시지를 원클릭으로 직접 발송.

### Phase 3: 오픈뱅킹 연동 자동 입금 확인
* **입금 알림 실시간 매칭:** 오픈뱅킹 API 또는 모바일 계좌 입금 SMS 문자를 연동하여, 외상값 입금 시 AI 비서가 계좌 내역을 분석해 장부 미수금을 자동으로 털어내는 자동 대사 시스템 구축.

### Phase 4: 비전 AI 기반의 종이 장부/송장 스캔
* **멀티모달 OCR 장부 입력:** 농가 현장에서 여전히 혼용되는 수기 영수증, 도매 청과 송장, 택배 우체국 송장 용지 사진을 촬영하면 Vision AI가 텍스트와 숫자를 스캔·파싱하여 디지털 장부에 1초 만에 자동 기록하는 지능형 모듈 탑재.
